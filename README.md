# Ironfront

Ett 2D-actionspel i webbläsaren. Du kör en stridsvagn och håller linjen mot våg efter våg av maskiner.

Öppna `index.html` i en webbläsare. Inget att installera, allt ligger i en fil.

## Styrning

| Tangent | Funktion |
| --- | --- |
| WASD / piltangenter | Kör |
| Mus | Sikta, håll vänster knapp för eld |
| Space / Shift | Dash (odödlig under rusningen) |
| E / högerklick | Overdrive: chockvåg + dubbel eldhastighet |
| F | Autoeld |
| P / Esc | Paus |
| M | Ljud av/på |

På mobil kör du med vänster tumme och siktar med höger. Lyfter du tummen skjuter tornet automatiskt på närmaste fiende.

## Innehåll

- Sju fiendetyper: drönare, löpare, skyttar, delare, bombare, bjässar och elitvarianter
- Bossen Dreadnought var femte våg, med ringsalvor, spiraler, rusningar och förstärkningar
- 17 uppgraderingar att välja mellan vid varje ny nivå, t.ex. extra pipor, rikoschett, sprängladdning, kedjeblixt, drönare och sköld
- Kombomultiplikator, rekord som sparas lokalt, minikarta och syntljud och musik gjorda med Web Audio
